# Checklists for everyone

These checklists are written for people who have **never coded**. No jargon is needed to use them. If a word is unfamiliar, look it up in the [glossary](../guides/glossary.md).

Print them, copy them into your notes app, or paste them into a chat with Claude and say "walk me through this checklist".

| Checklist | Use it | Time |
|---|---|---|
| [A. Before you start](A-before-you-start.md) | Once, before your first prompt on a new project | 15–20 min |
| [B. Every session](B-every-session.md) | At the start and end of each time you sit down to build | 2 min |
| [C. Before you share it](C-before-you-share.md) | Before anyone else uses what you built | 30–60 min |
| [D. Something went wrong](D-something-went-wrong.md) | The moment the AI does something you didn't expect | 2 min to start |

**The golden rule:** if any answer is "no" or "I don't know", stop and fix it or ask for help. "I don't know" is a perfectly good answer: it means it's time to ask.
