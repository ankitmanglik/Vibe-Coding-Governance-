# Checklist B: Every session

Use this each time you sit down to build. It takes two minutes.

## At the start

- [ ] **I've saved a copy (checkpoint) of where things are now.**
  *In Git this is a "commit". On app builders it may be called a "version" or "checkpoint".*
- [ ] **I know the ONE thing I want to get done this session.**
  *Small goals work. "Add a contact form" is good. "Make the app better" is not.*
- [ ] **I'm starting a fresh chat** (or I've reminded the AI of the project rules).
  *Why: in long chats, AIs can forget the rules you gave them. (VC-10)*
- [ ] **I know how to stop the AI** right now if I need to.

## While you work

Every time the AI asks to run something, ask yourself:

| If the AI wants to... | Do this |
|---|---|
| Delete, move, or "clean up" files | ❌ **Stop. Ask it to list exactly what will be affected first.** |
| Touch a database, "reset", or "migrate" | ❌ **Stop. Is this the practice copy? If unsure, say no.** |
| Send emails or messages | ❌ **Stop. Only in test mode, to yourself.** |
| Install something | ⚠️ Ask it: "Is this a well-known, widely used package?" |
| See a password or key | ❌ **Never paste it. Put it in the secret settings instead.** |
| Change one or two files for your request | ✅ Usually fine. Check the result. |

And:

- [ ] **One change at a time.** Ask → check it works → save a checkpoint → next.
- [ ] **When the AI says "done" or "fixed", I checked it myself.**
  *Why: AIs have said "no issues" about code that was sending thousands of emails. (VC-28)*
- [ ] **If the same problem comes back three times, I stop and ask a person.**

## At the end

- [ ] **Everything still works** (I tried the main things on my "done means" list).
- [ ] **I've saved a final checkpoint** with a short note of what changed.
- [ ] **My work is backed up somewhere other than my laptop** (for example, pushed to GitHub).
