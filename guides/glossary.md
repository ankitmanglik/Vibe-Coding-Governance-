# Glossary (plain English)

| Word | What it means |
|---|---|
| **Agent** | An AI that doesn't just answer but *does* things: runs commands, edits files, calls services. |
| **API** | A way for one program to talk to another (for example, your app asking an email service to send a message). |
| **API key / token / secret** | A password that a program uses. Whoever has it can act as you. |
| **Authentication** | Checking *who* someone is (logging in). |
| **Authorization** | Checking *what* someone is allowed to see or do. |
| **Backup** | A separate copy you can restore from if the original is lost. |
| **BOLA** | A bug where changing an ID (for example in a web address) lets you see someone else's data. |
| **Browser / client / front end** | The part of an app that runs on the user's device. Anything here is visible to anyone. |
| **Checkpoint / commit** | A save point in your project's history that you can go back to. |
| **CLAUDE.md** | A file in your project that Claude Code reads at the start of every session: a good place for your rules. |
| **CSRF** | A trick where another website makes your logged-in browser do something without you knowing. |
| **Database** | Where an app stores its information (users, orders, messages). |
| **Deploy** | Put your app online so others can use it. |
| **Dev / development** | Your practice copy. Mistakes here are fine. |
| **Diff** | A view showing exactly what changed between two versions. |
| **Environment variable / `.env`** | A safe place to store secrets outside your code. |
| **Git / GitHub** | Git is the undo history for your project; GitHub is a website that stores a copy of it online. |
| **`.gitignore`** | A list of files Git should never save (like your `.env` secrets file). |
| **Hook** | A small safety program that runs automatically before the AI does something, and can stop it. |
| **Loop** | Code that repeats. A broken loop can repeat forever. |
| **Package / library** | Ready-made code your project borrows. Some AI-suggested packages are fake. |
| **Production / prod** | The real, live version that real people use. |
| **Rate limit** | A cap on how often something can happen (for example, 5 login attempts per minute). |
| **Repository / repo** | The folder holding all your project's files and history. |
| **RLS (Row Level Security)** | A database setting that shows each person only their own rows of data. |
| **Server / back end** | The part of an app that runs on a computer you control, out of sight of users. Security checks belong here. |
| **Skill (Claude)** | A packaged set of instructions that teaches Claude how to do a specific job. |
| **Terraform** | A tool that creates and destroys cloud infrastructure from files. Powerful and dangerous. |
| **Vibe coding** | Building software by describing what you want to an AI, often without reading the code it writes. |
